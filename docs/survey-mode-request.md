# 조사 입력 모드 요구사항

> Claude Code에 이 파일을 주고 "docs/survey-mode-request.md대로 조사 입력 모드를 만들어줘. 먼저 계획을 보여주고, 내가 확인하면 구현해줘"라고 요청하세요.

## 목적

조사팀이 지금은 네이버 지도 캡처에 굿노트로 표시하고 나중에 옮기는데, 이를 **현장에서 아이패드로 우리 웹사이트에 바로 입력**하는 방식으로 바꾼다. 좌표를 네이버가 아닌 GPS 또는 우리 지도(브이월드)에서 얻기 위해서이기도 하다. 같은 화면을 사무실에서 굿노트 기록을 옮길 때도 쓴다.

## 들어가는 법

* 일반 이용자에게는 보이지 않게, 주소 뒤에 `?survey=1`을 붙였을 때만 조사 모드가 켜지게 한다.
* 처음 켤 때 조사자 이름을 한 번 입력받아 기기에 기억한다.

## 위치 정하기

* **현재 위치** 버튼: 아이패드 GPS로 위치를 잡고 정확도(±m)를 함께 표시. GPS는 https에서만 되므로 공개 사이트(GitHub Pages)에서 사용
* **지도에서 찍기**: 지도를 누르면 그 자리에 임시 핀
* 임시 핀은 드래그로 미세조정 가능. 위도·경도를 화면에 표시하고 복사 버튼 제공(좌표 찍기 모드 겸용)
* 좌표 출처를 자동 기록: `coordSource: "gps"` 또는 `"map"`

## 입력 항목 (분류를 고르면 해당 칸만 표시)

모든 O/X 항목에는 **"모름"** 선택지를 둔다(모름 → 지도에 "확인불가"). 큰 버튼으로, 타이핑을 최소화한다.

|분류|항목|굿노트 표기와의 대응|
|-|-|-|
|계단|칸수(숫자, +/− 버튼), 위치 설명, 대체 경로 메모|네모 + 괄호 안 칸수|
|화장실|위치 설명, 장애인화장실(O/X/모름), 개방(O/X/모름), 개방시간(매일 같은 시간 / 요일별 / 24시간 / 모름), 접근경로 단차·계단·경사로(각 O/X/모름)|✔ + "장X, 개방O, 8\~22, 계단O, 경사로X"|
|벤치|개수(+/− 버튼), 위치 설명|하트 개수|
|AED|설치 위치 설명, 이용 가능 시간(건물 개방시간)||
|쓰레기통|위치 설명||
|병원·약국·소방서·지구대|이름, 현장 확인 메모(운영시간은 공공데이터 우선)||
|가로등|개수, 위치 — 공공데이터 현장 검증용|(★ 표시 = 가로등)|
|보행 구간(선)|지도에서 점을 차례로 눌러 선 그리기, 구분(인도/차도/보차혼용), 유효 폭(m), 포장, 연석 경사로(O/X/모름), 경사 메모|(빨간 선의 의미 사용자 확인 필요)|

공통 항목: 사진(아이패드 카메라로 촬영, 여러 장), 메모, 조사자(자동), 조사일시(자동, 서울 시간), 확인 방법(자동 `field` = 현장확인).

## 저장과 내보내기

* 기기 안에 저장(IndexedDB). 인터넷이 잠깐 끊겨도 입력이 사라지지 않게
* 사진은 업로드 전에 긴 변 1600px 정도로 줄여 저장
* "오늘 입력한 목록" 화면: 지도에 임시 핀으로 표시, 눌러서 수정·삭제
* **내보내기** 버튼: `survey-YYYYMMDD-조사자.zip` (JSON + photos/ 폴더) 다운로드. 확인용 CSV도 함께
* 조사 기록은 공개 지도에 바로 보이지 않는다. 검토 후 합칠 때만 반영

## 합치기 스크립트

* 내보낸 zip을 `survey-inbox/`에 넣고 실행하면 `data/places.js`, `data/roads.js`, `data/streetlights.js`에 합치는 스크립트(Node)
* 같은 분류가 10m 안에 이미 있으면 중복 후보로 표시하고 사람이 고르게 한다(자동 덮어쓰기 금지)
* 기존 항목을 다시 조사한 경우 `verification.date`만 갱신하고 이전 값과 달라진 항목을 보고
* 사진은 `photos/`로 옮기고 정보창에 표시

## 지켜야 할 것

* CLAUDE.md의 원칙(안전 평가 금지, 확인 방법·날짜 표시, 객관 정보만)을 입력 화면 문구에도 적용
* 네이버 지도 캡처 위치를 좌표로 환산하는 기능은 만들지 않는다
* 아이패드 사파리 세로·가로 모두에서 쓰기 편하게, 버튼은 손가락으로 누르기 충분한 크기

## 사용자에게 먼저 물어볼 것

* 굿노트의 ★ 별 표시, 빨간 선, 파란/빨간 동그라미가 각각 무엇을 뜻하는지
* 조사자가 여러 명이면 이름 목록을 미리 넣어둘지
