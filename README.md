# 종로 보행환경 정보지도 — 기초틀

현장 조사 결과를 공공·오픈 데이터 위에 올리는 지도 웹사이트의 뼈대입니다.
지금 들어 있는 핀과 구간은 **모두 형식 확인용 샘플**(이름에 `[샘플]`)이며 실제 정보가 아닙니다.

## 실행
- 가장 간단: `index.html`을 브라우저로 열기
- 권장: 폴더에서 `npx serve .` 실행 후 표시되는 주소로 접속

## 파일 구조
| 파일 | 역할 |
|---|---|
| `index.html` | 화면 틀, 원칙 문구, 필터 |
| `style.css` | 디자인 |
| `app.js` | 지도·필터·운영시간 계산·정보창·제보 |
| `data/bounds.js` | 조사 범위 좌표 |
| `data/places.js` | 시설(핀) 데이터 |
| `data/roads.js` | 보행 구간(인도/차도/보차혼용) 데이터 |
| `data/streetlights.js` | 가로등·보안등 위치·개수 데이터 |
| `survey.js` / `survey.css` | 조사 입력 모드(`?survey=1`일 때만 동작) |
| `photos/` | 지도 정보창에 나오는 위치 사진 |
| `scripts/merge-survey.mjs` | 조사 입력 모드에서 내보낸 기록을 `data/*.js`에 합치는 스크립트 |
| `scripts/build-onefile.mjs` | 카톡 전달용 `종로보행지도_한파일.html` 만들기 |

## 들어 있는 기능
- 분류별 필터(화장실·벤치·계단·AED·병원·약국·소방서·지구대·쓰레기통)
- "지금 이용 가능한 곳만": 서울 시간 기준으로 운영시간을 계산해 바로 걸러냄(자정 넘는 영업 포함). 운영시간 확인불가 시설은 제외하고 몇 곳 제외됐는지 표시
- 핀 클릭 시 하단 정보창: 분류별 항목(계단 칸수, 화장실 장애인칸·개방시간·접근경로 등), 사진 자리
- 모든 정보에 `현장확인 / 기관확인 / 확인불가` + 최종확인 날짜. 확인불가 핀은 점선 테두리
- 시민 제보(폐쇄됨/철거됨/공사중 등): 원본을 바로 바꾸지 않고 '검토 전'으로 함께 표시
- 보행 구간은 폭·포장·연석 경사로·경사 같은 측정값만 표시. "안전한 길" 같은 평가 없음
- 상단 고정 원칙 문구

> 시민 제보는 지금 **각자 브라우저에만 저장**됩니다(프로토타입). 실제로 공유하려면 백엔드가 필요합니다(아래 '다음 단계').

## 조사 입력 모드
현장(아이패드)이나 사무실(굿노트 기록 옮기기)에서 지도에 바로 입력하는 화면입니다.

- **켜는 법**: 주소 뒤에 `?survey=1` → `https://hy15712.github.io/omni/?survey=1`. 일반 이용자 화면에는 나오지 않습니다. 처음 켤 때 조사자 이름을 한 번 입력합니다.
- **위치**: 지도를 최대한 확대한 뒤 정확한 위치를 눌러 찍습니다(조원 아이패드가 Wi-Fi 모델이라 GPS가 없음). 핀은 끌어서 옮길 수 있고 좌표 복사 버튼이 있습니다. `📍 내 위치 근처로 지도 이동`은 대략 위치(파란 원)로 지도만 옮겨 줍니다(https 주소에서만). 보행 구간은 지도에서 점을 차례로 눌러 선을 그립니다.
- **조사일**: 위쪽 띠에서 바꿀 수 있습니다(지난 답사 기록을 옮길 때). 창을 닫기 전까지 유지됩니다.
- **입력**: 분류를 고르면 해당 칸만 나옵니다. 있음/없음/모름/– 큰 버튼, 개수는 −/+ 버튼. **모름** = 확인했지만 알 수 없음 → 지도에 ‘확인불가’. **–** = 기록 안 함(기본값) → 지도 정보창에 그 줄이 나오지 않음. 화장실·AED는 위치 사진 칸이 맨 위에 있고 첫 사진이 대표 사진입니다.
- **저장**: 이 기기 브라우저 안에 바로 저장됩니다(인터넷이 끊겨도 유지). 사진은 긴 변 1600px로 줄여 저장합니다. 비공개(개인정보 보호) 모드에서는 저장되지 않습니다.
- **기록 목록**: 저장한 기록은 지도에 노란 점선 핀으로 보이고, 눌러서 수정·삭제할 수 있습니다.
- **내보내기**: `survey-날짜-이름.zip`(기록 JSON, 엑셀 확인용 CSV, 사진)을 저장하거나 카톡·AirDrop으로 공유합니다.
- **지도 반영**: 조사 기록은 공개 지도에 바로 나오지 않습니다. zip을 모아 Claude Code에 올리면 검토 후 합칩니다(`scripts/merge-survey.mjs`, 사용법은 파일 맨 위 주석). 같은 분류가 10m 안에 이미 있으면 중복 후보로 표시되고 사람이 고릅니다.
- 사진은 공개됩니다. 사람 얼굴·차 번호판이 나오지 않게 찍어 주세요.

## 가로등 격자
- 필터의 **가로등** 칩을 켜면 조사 범위를 약 50m×50m 칸으로 나눠, 지도 전체가 어두워지고 칸마다 가로등·보안등 개수가 많을수록 밝게 표시됩니다(0 / 1–3 / 4–6 / 7+). 조사 범위 밖은 자료가 없어 가장 어둡게 덮입니다.
- 칸을 누르면 개수, 가로등·보안등 구분, 확인 방법, 자료 기준일이 나옵니다. 지도를 충분히 확대(18레벨 이상)하면 등 하나하나의 위치가 점으로 보입니다.
- 데이터: `data/streetlights.js` (지금은 샘플). 칸 크기는 `app.js`의 `GRID_M`, 어둡기·노란빛 단계는 `LIGHT_STEPS`, 번짐 정도는 `style.css`의 `.night-pane{filter:blur(8px)}`에서 바꿀 수 있습니다.
- 표시하는 것은 설치 개수이며 실제 조도(밝기)가 아닙니다. 범례와 정보창에 이 안내를 유지하세요.

## 좌표 범위 확정하기
`data/bounds.js`에 넣은 값은 사진 속 사각형(종각역–종로3가역–을지로3가역–을지로입구)을 기준으로 한 **대략값**입니다.

정확히 정하는 방법(네이버 API를 거치지 않는 방법만):
1. **bboxfinder.com** 접속 → 왼쪽 위 사각형 도구로 조사 범위를 드래그 → 아래 `Box` 값이 `서경,남위,동경,북위` 순서로 나옴 → `bounds.js`의 west, south, east, north에 넣기
2. 또는 **geojson.io**에서 사각형을 그리면 오른쪽에 꼭짓점 좌표가 나옴
3. 또는 **openstreetmap.org** → 상단 '내보내기' → '다른 영역을 수동으로 선택'으로 범위 지정 시 네 좌표 표시

이 사이트들은 OpenStreetMap 기반이라 결과 좌표를 저장·배포해도 네이버 약관 문제가 없습니다.

## 시설 좌표를 얻는 방법
- **현장 GPS**: 조사할 때 휴대폰으로 그 자리 좌표 기록(`coordSource: "gps"`). 오차가 수 m 있을 수 있으니 지도에서 확인 후 미세조정
- **geojson.io / bboxfinder.com에서 클릭**: 배경이 OSM이므로 좌표를 저장해도 됨
- **공공데이터에 이미 들어 있는 좌표**(`coordSource: "public"`)
- ❌ 네이버 지도에서 좌표를 복사하거나 네이버 Geocoding으로 변환한 값은 저장하지 않기

## 배경지도
- 기본값은 **OpenFreeMap**(OpenStreetMap 기반, 키·가입 불필요). 지명은 한글로, 3D 건물은 끄도록 설정되어 있습니다. 출처 표시는 지우면 안 됩니다.
- 쓰지 않는 것: OSM 공식 타일 서버(파일로 연 페이지 차단), CARTO 무료 타일(2026년 8월 말부터 키 없으면 워터마크).

### 브이월드 배경지도 쓰기 (네이버·카카오 지도와 비슷한 화면, 지하철역 표시)
1. vworld.kr 회원가입 → 오픈API → 인증키 → **인증키 발급**
2. 활용 API에서 **WMTS/TMS API**에 체크
3. 서비스 URL: 테스트 단계는 `http://localhost`, 공개할 때 실제 사이트 주소를 추가
4. 받은 키를 `data/config.js`의 `VWORLD_KEY: ""` 따옴표 안에 붙여넣기
5. 지도가 안 뜨면 파일을 더블클릭하지 말고 폴더에서 `npx serve .` 또는 `python -m http.server`로 실행해 `http://localhost:...`로 접속 (키가 등록된 주소에서만 동작)

브이월드는 국토교통부의 무료 공공 지도이며 이용조건은 공공저작물 출처표시입니다. 화면의 "브이월드(국토교통부)" 표시를 유지하세요.
- OSM에서 **데이터 자체**(도로선 등)를 가져와 우리 데이터베이스로 배포하면 ODbL 조건(출처 표시, 동일 조건 공유)이 붙습니다.
